# Picture Hunt — Demo Runbook

## URLs
- **App:** https://venturelabai.github.io/picture-hunt/play/
- **Landing (the pitch):** https://venturelabai.github.io/picture-hunt/

## Before the demo (~2 min)
1. On the demo phone, open the **App URL** in a fresh browser tab. Hold the phone **upright** — the game is portrait-only.
2. **Unlock everything for the demo:** tap the **"🌍 Learn a Language 🔒"** button (or any locked category) → the unlock screen opens → enter code **`LAUNCH2026`** → Unlock. This turns on all 10 categories, Story Quests, and bilingual mode.
3. Turn the phone **volume up**. Have a few easy objects nearby (apple, cup, book, shoe, a stuffed animal).
4. Make sure the phone has **internet** — the AI photo-check needs it.

## The demo path (the "wow")
1. **Landing page** — the pitch: *your kid learns a language by finding real things*, 10 languages, one-time $19.99 (no subscription).
2. **Core loop** — tap a category (e.g. **Things**) → the fox voice asks for an item → point the camera at the real object → the AI confirms → celebration. Do 2–3 finds.
3. **Story Quests** (the retention engine) — on the home screen tap the purple **Story Quests** card → pick **Bear's Breakfast** → a guided adventure narrated in the fox voice (this used to be a robot voice — now it's the real one).
4. **Bilingual** — tap **"Learning …"** → choose **Spanish** → during a hunt you'll hear *"Can you find an apple? ¡Una manzana!"* with the foreign word on screen.

## Good to know
- The voice is the new **coral** fox across the whole app, normalized to a clear, louder level.
- The **Buy** button shows *"checkout opens soon"* — Stripe isn't wired yet (deliberate; the unlock-code flow works). If asked: monetization is fully built and one Stripe Payment Link away from live.
- **Everything is adjustable post-demo in minutes** — voice, volume, copy, any spoken line — just regenerate the clip(s) and push; it's live in ~60s, no app-store review.
- If a returning/installed copy looks stale, fully close the tab and reopen — the cache version was bumped (v96), so it refetches on next launch.
